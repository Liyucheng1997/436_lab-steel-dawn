# 钢铁黎明 · STEEL DAWN

一款跑在浏览器里的原创 3D 即时战略游戏：采集晶矿、建设基地、集结部队、摧毁敌方全部建筑。

基于 Three.js，所有模型、贴图和音效都由代码程序化生成，仓库里没有任何美术或音频素材文件。

## 运行

需要 Node.js 20 以上。

```bash
npm install
npm run dev
```

然后打开 <http://localhost:5173>，选择难度开始。

打包静态文件：

```bash
npm run build
```

## 玩法

- **阵营**：苍穹同盟（玩家）对熔炉军团（电脑）。
- **建筑**：指挥中心、聚变电站、晶矿精炼厂、兵营、战车工厂、科技中心、机炮塔、轨道炮塔。
- **单位**：步枪兵、火箭兵、晶矿采集车、游隼突击车、猎犬主战坦克、泰坦重型坦克、雷霆自行火炮。
- **系统**：电力、科技树、建造队列、建筑部署、集结点、战争迷雾、小地图、编队、护甲克制。
- **电脑对手**：简单 / 普通 / 困难三档，会自行发展、采矿、分波进攻和回防。

## 操作

| 操作 | 按键 |
| --- | --- |
| 选择 / 框选 | 鼠标左键（双击选中屏幕内同类单位） |
| 移动 / 攻击 / 采矿 / 设置集结点 | 鼠标右键 |
| 平移镜头 | WASD 或方向键，鼠标中键拖动 |
| 缩放 / 旋转镜头 | 滚轮 / Q、E |
| 进攻移动 | F 后左键点击目标 |
| 停止 | X |
| 编队 / 选中编队 | Ctrl + 数字 / 数字 |
| 回到基地 / 跳到警报位置 | H / 空格 |
| 出售选中建筑 | Delete |
| 调节游戏速度（1× ~ 4×） | + / - |
| 暂停 / 静音 | P 或 Esc / M |

建筑造好后，点击侧栏图标，再在己方建筑附近的空地上点击部署。

## 代码结构

| 文件 | 内容 |
| --- | --- |
| `src/config.js` | 阵营、武器、单位、建筑的全部数值 |
| `src/models.js` | 单位与建筑的程序化模型 |
| `src/terrain.js` | 地图生成与地形、水面、植被、晶矿渲染 |
| `src/game.js` | 经济、生产、移动、战斗、采矿 |
| `src/ai.js` | 电脑对手 |
| `src/pathfinding.js` | 网格 A* 寻路 |
| `src/input.js` | 镜头、选择、指令、建筑放置 |
| `src/hud.js` | 资源栏、建造栏、小地图、血条 |
| `src/fx.js` / `src/audio.js` / `src/fog.js` | 粒子特效、合成音效、战争迷雾 |
